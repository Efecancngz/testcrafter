# Alembic Migrations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `Base.metadata.create_all(engine)` with Alembic-managed migrations as the single source of truth for the production/dev database schema, while keeping `create_all` for the fast in-memory test database (a deliberate, documented split, not an inconsistency).

**Architecture:** Standard Alembic project (`backend/alembic.ini`, `backend/alembic/env.py`, `backend/alembic/versions/`) wired to `app.db.Base.metadata` for autogenerate and to the same database URL `app/db.py` already uses. One initial migration captures the current schema exactly. Docker's `CMD` runs `alembic upgrade head` before `uvicorn` starts.

**Tech Stack:** `alembic` (new dependency) on top of the existing SQLAlchemy setup.

## Global Constraints

- `backend/tests/conftest.py`'s `db_session` fixture keeps using `Base.metadata.create_all(engine)` against `sqlite:///:memory:` — this is intentional, do not change it to run migrations.
- Migration files are committed exactly as autogenerate produces them and are never hand-edited after being committed — if a change is needed, generate a new migration.
- Follow existing repo conventions: no comments except non-obvious WHY, no speculative abstractions.
- Never add a "Co-Authored-By: Claude" (or any AI attribution) trailer to commits — hard rule for this repo.
- CI workflow / `alembic check` automation is explicitly out of scope — no GitHub Actions workflow exists in this repo yet, and adding one is a separate, larger piece of work.

- [ ] **Step 1: Write the migration-consistency test**

Create `backend/tests/test_alembic.py`:

```python
from pathlib import Path
from alembic import command
from alembic.config import Config
from sqlalchemy import create_engine, inspect
from app.db import Base
from app import models  # noqa: F401 — import registers all model classes on Base.metadata

BACKEND_DIR = Path(__file__).resolve().parent.parent

def test_alembic_upgrade_head_matches_current_models(tmp_path):
    db_path = tmp_path / "alembic_check.db"
    db_url = f"sqlite:///{db_path}"

    alembic_cfg = Config(str(BACKEND_DIR / "alembic.ini"))
    alembic_cfg.set_main_option("sqlalchemy.url", db_url)
    alembic_cfg.set_main_option("script_location", str(BACKEND_DIR / "alembic"))
    command.upgrade(alembic_cfg, "head")

    engine = create_engine(db_url)
    inspector = inspect(engine)
    migrated_tables = set(inspector.get_table_names()) - {"alembic_version"}
    model_tables = set(Base.metadata.tables.keys())

    assert migrated_tables == model_tables

    for table_name in model_tables:
        migrated_columns = {col["name"] for col in inspector.get_columns(table_name)}
        model_columns = {col.name for col in Base.metadata.tables[table_name].columns}
        assert migrated_columns == model_columns, f"column mismatch in {table_name}"
```
